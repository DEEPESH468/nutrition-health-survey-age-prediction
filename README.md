## 📌 Overview

This project predicts whether a person belongs to the Adult or Senior age group using health survey data from NHANES.

The solution was developed as part of an online Machine Learning Hackathon.

---

## 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Google Colab

---

## 📊 Dataset

The dataset contains health-related information including:

- BMI
- Blood Glucose
- Cholesterol
- Insulin
- Physical Activity
- Gender

---

## 🤖 Machine Learning Model

**Random Forest Classifier**

Validation Accuracy:

**82.10%**
